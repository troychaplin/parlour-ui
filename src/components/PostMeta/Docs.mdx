# Post Meta

The byline for a post: the author's avatar, name and a short line about them, with the published and updated dates. Renders a `<div>` holding the author block and the dates, each date in a `<time>` element.

## When to use

- Below a post's header, or at the end of a post, to say who wrote it and when.
- Add `updated` when a post has changed since it was published, so readers know how current it is.
- It isn't for the post list: rows in [`ContentList`](?path=/docs/components-content-content-list--docs) show their dates with `ContentListMeta`.

## Import

```tsx
import { PostMeta } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Author and published date
<PostMeta name="Troy Chaplin" published="2026-04-21" />

// Everything
<PostMeta
    name="Troy Chaplin"
    details="Developer · Ottawa"
    avatar="/images/troy.jpg"
    published="2026-04-21"
    updated="2026-04-24"
/>

// Without the rule above it
<PostMeta name="Troy Chaplin" published="2026-04-21" divider={false} />
```

Pass dates as ISO strings (`YYYY-MM-DD`). The component writes them out as "21 April 2026" and keeps the ISO value in each `<time>`'s `dateTime`. They're formatted in UTC, so the server and the browser always show the same day.

## CSS classes

| Class                        | When applied                                           |
| ---------------------------- | ------------------------------------------------------ |
| `parlour-post-meta`          | Always — base class                                    |
| `parlour-post-meta--divider` | `divider` is `true` (default) — the rule above the row |
| `parlour-post-meta__author`  | Always — the avatar, name and details                  |
| `parlour-post-meta__avatar`  | `avatar` is set — the `<img>`                          |
| `parlour-post-meta__name`    | Always — the `<p>` holding `name`                      |
| `parlour-post-meta__details` | `details` is set                                       |
| `parlour-post-meta__dates`   | `published` or `updated` is set                        |

The colours are custom properties set on `parlour-post-meta` — `--parlour-post-meta-name`, `-muted` and `-rule` — so you can override them there. The row wraps on narrow screens; the dates right-align beside the author above 600px and left-align below it. A `className` you pass is appended after the generated classes, and other props go on the outer `<div>`.

## Accessibility

- Each date is a `<time>` whose `dateTime` holds the ISO date, so software can read it however it's displayed. The "Published" and "Updated" labels are real text, so screen readers read them with the dates.
- The avatar's `alt` is empty by default, since the name sits right beside it and repeating it adds nothing. Set `avatarAlt` only if the image shows something the name doesn't.
- The dates' capitals come from CSS, so screen readers don't spell them out.
- The muted colour, `--parlour--color-neutral-600`, meets WCAG AA for small text on the light backgrounds; in dark and medium Containers it switches to `--parlour--color-neutral-300`.

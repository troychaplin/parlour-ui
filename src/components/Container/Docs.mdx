# Container

A band of the page that sets its width, background, padding and borders. Renders a `<div>` by default, or the element set by `as`, with an inner `<div>` that constrains its children to `contentWidth`.

## When to use

- Split a page into sections inside [`Main`](?path=/docs/components-template-parts-main--docs): a hero, a grid of cards, a list of posts. Stack full-width Containers with different `color`s to alternate bands down the page.
- Use `maxWidth="alignfull"` with `contentWidth="alignwide"` for the common band whose background runs edge to edge while its content stays at the wide width.
- Use `border` to rule a section off from its neighbours, such as a hairline between two bands of the same colour.
- It isn't for small surfaces inside a section — use [`Card`](?path=/docs/components-cards-card--docs) for those.

## Import

```tsx
import { Container } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Content width, no background
<Container>...</Container>

// Full-width band with wide content
<Container color="pale" maxWidth="alignfull" contentWidth="alignwide">...</Container>

// A boxed light Container, bordered all round
<Container color="light" border="all">...</Container>

// A rule above a dark band
<Container color="dark" border="top" maxWidth="alignfull">...</Container>

// A section landmark with a name
<Container as="section" aria-label="Releases" color="light">...</Container>
```

### Colours

`color` sets the background and adds block padding (`--parlour--spacing-5-x-large`). `medium` and `dark` turn the text and headings white. Without `color`, a Container has no background and no block padding.

<Canvas of={ContainerStories.Colors} />

### Borders

`border` draws a `1px` rule on the `top`, the `bottom`, `both` (top and bottom) or `all` four sides. It's `none` by default for every colour. The rule's colour comes from the background:

| `color`  | Background                     | Border                         |
| -------- | ------------------------------ | ------------------------------ |
| `white`  | `--parlour--color-white`       | `--parlour--color-neutral-300` |
| `pale`   | `--parlour--color-neutral-50`  | `--parlour--color-neutral-300` |
| `light`  | `--parlour--color-neutral-200` | `--parlour--color-neutral-300` |
| `medium` | `--parlour--color-neutral-900` | `--parlour--color-neutral-700` |
| `dark`   | `--parlour--color-neutral-950` | `--parlour--color-neutral-900` |

These are the pairings the rest of the library uses — `Card`'s borders, `GridGroup`'s dividers, and the rules in `ContentList` and `Pagination`. `border` only applies to a Container with a `color`, since only those have the block padding that keeps a rule off the content.

### Borders on full-width bands

On a full-width Container, `all` draws only the top and bottom: side borders would sit against the edges of the viewport.

### Stacked bands

Full-width Containers stack with no gap between them. Where one has a bottom border and the next a top border, they share a single rule instead of drawing two.

## CSS classes

| Class                                  | When applied                                                                |
| -------------------------------------- | --------------------------------------------------------------------------- |
| `parlour-layout`, `parlour-container`  | Always — base classes                                                       |
| `is-layout-constrained`                | Always — constrains children to the content and wide widths                 |
| `{maxWidth}`                           | Always — `aligncontent` (default), `alignsmall`, `alignwide` or `alignfull` |
| `parlour-container--{color}`           | `color` is set                                                              |
| `parlour-container--no-gap`            | `color` is set — controls the spacing between stacked Containers            |
| `parlour-container--border-{border}`   | `color` is set and `border` isn't `none` (the default)                      |
| `parlour-container--radius-{radius}`   | Always — `borderRadius`, `md` by default; ignored on `alignfull`            |
| `has-global-padding`, `{contentWidth}` | On the inner `<div>` — `contentWidth` is `aligncontent` by default          |
| `has-root-padding`                     | On the inner `<div>`, when `color` is set                                   |

Each colour class sets `--parlour-container-border`, which the border classes read; override it on a Container to recolour its rule. A `className` you pass is appended after the generated classes. All other props, including `style` and `aria-*`, go on the outer element, so a background set there spans the full `maxWidth` while the content stays at `contentWidth`.

Two layout rules use `!important`, so inline styles can't override them: inside a constrained parent such as `Main`, any `maxWidth` but `alignfull` is centred with `margin-inline: auto !important`, and `alignsmall` sets its `max-width` with `!important`.

## Design tokens

| Token                                                           | Used for                                                       |
| --------------------------------------------------------------- | -------------------------------------------------------------- |
| `--parlour--color-white`                                        | `white` background; text on `medium` and `dark`                |
| `--parlour--color-neutral-50`                                   | `pale` background                                              |
| `--parlour--color-neutral-200`                                  | `light` background                                             |
| `--parlour--color-neutral-900`                                  | `medium` background; `dark` border                             |
| `--parlour--color-neutral-950`                                  | `dark` background                                              |
| `--parlour--color-neutral-300`                                  | `white`, `pale` and `light` borders                            |
| `--parlour--color-neutral-700`                                  | `medium` border                                                |
| `--parlour--spacing-5-x-large`                                  | Block padding when `color` is set                              |
| `--parlour--spacing-3-x-large` / `-4-x-large`                   | Side padding, below / above the tablet breakpoint              |
| `--parlour--spacing-2-x-large`                                  | Gap between stacked coloured Containers that aren't full width |
| `--parlour--radius-sm` / `-md` / `-lg` / `-xl` / `-full`        | `borderRadius`                                                 |
| `--parlour--layout-small-size` / `-content-size` / `-wide-size` | `alignsmall`, `aligncontent` and `alignwide` widths            |

The `1px` border width is a raw value rather than a design token.

## Accessibility

- `Container` renders a `<div>`, which has no role. Use `as` to give a band meaning: `as="section"` with an `aria-label` or `aria-labelledby` becomes a region landmark, and `header`, `footer`, `nav` and `aside` map to their own landmarks. Give each landmark of the same kind a distinct name.
- `medium` and `dark` set white text and headings so content stays readable; check the contrast of any colour you add yourself against the background.
- Borders are decoration. They aren't announced and never carry meaning on their own.

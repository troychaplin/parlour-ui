# ContentList

A ruled list of posts or other entries, where each row is built from part components you choose and order. Renders a `<ul>` by default, or the element set by `as`, with a strong rule above the first row and a light rule under each one.

## When to use

- List essays, releases or other entries in an index: a number, a date, a category, a thumbnail and a title, in whichever combination and order the layout needs.
- Put the same parts in the same order in every row, and the columns line up from row to row.
- Use a [`GridGroup`](?path=/docs/components-layout-grid-group--docs) of [`Card`](?path=/docs/components-cards-card--docs)s or [`ProjectCard`](?path=/docs/components-cards-project-card--docs)s for tiles, not rows.

## Import

```tsx
import {
    ContentList,
    ContentListItem,
    ContentListIndex,
    ContentListMeta,
    ContentListLabel,
    ContentListImage,
    ContentListBody,
    ContentListTitle,
    ContentListExcerpt,
} from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Index, label, title and excerpt, with the date at the end
<ContentList maxWidth="alignwide">
    <ContentListItem>
        <ContentListIndex>No. 184</ContentListIndex>
        <ContentListLabel>WordPress</ContentListLabel>
        <ContentListBody>
            <ContentListTitle href="/writing/184">Block-based theme.json…</ContentListTitle>
            <ContentListExcerpt>After three years…</ContentListExcerpt>
        </ContentListBody>
        <ContentListMeta align="end">
            <span>21 Apr 2026</span>
            <span>11 min</span>
        </ContentListMeta>
    </ContentListItem>
</ContentList>

// A numbered contents list with thumbnails
<ContentList as="ol">
    <ContentListItem>
        <ContentListIndex variant="accent">01</ContentListIndex>
        <ContentListImage src="/thumb.jpg" alt="" />
        <ContentListLabel color="muted">Essay · WordPress</ContentListLabel>
        <ContentListBody>…</ContentListBody>
    </ContentListItem>
</ContentList>

// Smaller, for a half-width column
<ContentList size="small">…</ContentList>
```

### Parts

| Part                 | Renders                                                                                                      |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| `ContentListItem`    | One row, an `<li>` (or `<div>` with `as="div"` when the list is a `<div>`)                                   |
| `ContentListIndex`   | A number. `variant="muted"` (default) is small mono text; `variant="accent"` is larger, in the accent colour |
| `ContentListMeta`    | Stacked lines, one per child — a date over a read time. `align="end"` right-aligns them for the end of a row |
| `ContentListLabel`   | A category. `color="accent"` (default) or `color="muted"`                                                    |
| `ContentListImage`   | A square thumbnail `<img>`. `alt` is required; pass `alt=""` when the title already says what it shows       |
| `ContentListBody`    | Takes the width the other parts leave; holds the title and excerpt                                           |
| `ContentListTitle`   | An `<h3>` (or `level` 2–4). With `href`, its text is a link that makes the whole row clickable               |
| `ContentListExcerpt` | A paragraph under the title                                                                                  |

## CSS classes

| Class                                                     | When applied                                                            |
| --------------------------------------------------------- | ----------------------------------------------------------------------- |
| `parlour-content-list`                                    | Always — base class on the list                                         |
| `parlour-content-list--{size}`                            | Always — the `size` value, e.g. `parlour-content-list--large` (default) |
| `parlour-content-list--bg-hover-{name}`                   | `backgroundHover` is set — `light` or `dark`                            |
| `aligncontent` / `alignwide` / `alignfull` / `alignsmall` | The `maxWidth` value, as a bare shared class                            |
| `parlour-content-list__item`                              | On `ContentListItem`                                                    |
| `parlour-content-list__index` + `--{variant}`             | On `ContentListIndex` — `--muted` (default) or `--accent`               |
| `parlour-content-list__meta` + `--{align}`                | On `ContentListMeta` — `--start` (default) or `--end`                   |
| `parlour-content-list__label` + `--{color}`               | On `ContentListLabel` — `--accent` (default) or `--muted`               |
| `parlour-content-list__image`                             | On `ContentListImage`                                                   |
| `parlour-content-list__body`                              | On `ContentListBody`                                                    |
| `parlour-content-list__title`                             | On `ContentListTitle`                                                   |
| `parlour-content-list__link`                              | On the title's link when `href` is set — its `::after` covers the row   |
| `parlour-content-list__excerpt`                           | On `ContentListExcerpt`                                                 |

Each part's `className` is appended after its own classes.

Each fixed part takes its width from a custom property set on the list: `--parlour-content-list-index-width` (`5rem`), `--parlour-content-list-meta-width` (`8rem`), `--parlour-content-list-label-width` (`9rem`) and `--parlour-content-list-image-size` (`5rem`); `size="small"` narrows them to `3.5rem`, `6rem`, `6rem` and `3.5rem`. Set one on the list, through `style` or your own class, to resize that column in every row. The list's colours are custom properties as well (`--parlour-content-list-muted`, `-accent`, `-title`, `-rule` and so on), which the dark and medium Container rules swap.

| `--parlour--color-accent-primary-light`                    | The same in dark and medium Containers                                       |

The column widths, the `1px` rules, the `2px` focus outline, the mono parts' `0.1em` letter spacing and the title's `-0.5px` letter spacing are raw values rather than design tokens.

## Accessibility

- The default `<ul>` (or `as="ol"` for a numbered list) is announced as a list with its item count. The list gets `role="list"`, because removing the bullets otherwise makes Safari and VoiceOver stop announcing it as one.
- The row's link is the title text, so screen readers announce a short link and voice-control users can say what they see (WCAG 2.5.3 Label in Name). An `::after` overlay stretches it over the row, so a click anywhere on the row follows it. While it has focus, the outline is drawn around the whole row.
- Use one linked title per row. The overlay sits above the row's other content, so another link inside the row needs `position: relative` and a `z-index` to stay clickable.
- `ContentListImage` requires `alt`. Thumbnails usually repeat what the title says, so pass `alt=""` to have screen readers skip them.
- The index, meta and label come before the title in reading order. Write them so they make sense read aloud, e.g. "No. 184" rather than a bare number.
- `ContentListTitle` is a client component (`'use client'`) because it reads [`LinkProvider`](?path=/docs/components-utilities-linkprovider--docs); the other parts are not. Server components can render all of them.
- Muted text, accent text and titles pass WCAG AA on light sections and in dark and medium Containers.

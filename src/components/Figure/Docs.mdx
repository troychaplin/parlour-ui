# Figure

An image or media wrapper with an optional caption, a size and a float alignment. Renders a `<figure>` around your image or media, with the caption in a `<figcaption>`.

## When to use

- Place an image in article or body copy, floated left or right so the text wraps around it.
- Give an image a caption that's tied to it for assistive technology.
- Don't use it for decorative background images, or for images inside cards — those belong in the card's own markup.

## Import

```tsx
import { Figure } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Full width, no caption
<Figure>
    <img src="/photo.jpg" alt="A description of the photo" />
</Figure>

// With a caption
<Figure caption="The workshop in spring.">
    <img src="/workshop.jpg" alt="A wood workshop with tools on the walls" />
</Figure>

// At the wide layout width, centred in Main or a Container
<Figure maxWidth="alignwide">
    <img src="/panorama.jpg" alt="A panorama of the harbour at dusk" />
</Figure>

// Medium width, floated left with text wrapping around it
<Figure size="md" align="left">
    <img src="/detail.jpg" alt="A close-up of a dovetail joint" />
</Figure>
```

### Max widths

`maxWidth` sizes a block figure with the shared layout widths — `alignsmall` (600px), `aligncontent` (768px), `alignwide` (1152px) and `alignfull` (the full viewport) — the same as `Container`, `ContentList` and `SectionHeader`. It applies when the figure is a direct child of a constrained parent such as [`Main`](?path=/docs/components-template-parts-main--docs) or a `Container`. An `alignfull` figure loses its rounded corners, since it runs to the viewport edges.

`maxWidth` is for block figures, so it's ignored when `align` is `left` or `right`: a floated figure keeps its `size` (`xs` to `lg`), which is small enough to leave room for the text beside it.

## CSS classes

| Class                                                     | When applied                                                                    |
| --------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `parlour-figure`                                          | Always — base class on the `<figure>`                                           |
| `parlour-figure--{size}`                                  | Always — the `size` value: `xs`, `sm`, `md`, `lg` or `full` (default)           |
| `parlour-figure--{align}`                                 | `align` is `left`, `right` or `center`                                          |
| `alignleft` / `alignright`                                | `align` is `left` / `right` — opts out of the constrained layout's auto margins |
| `alignsmall` / `aligncontent` / `alignwide` / `alignfull` | `maxWidth` is set and the figure isn't floated                                  |
| `parlour-figure__inner`                                   | Always — the frame around the media and caption; rounds the corners             |
| `parlour-figure__caption`                                 | `caption` is set — on the `<figcaption>`                                        |

The sizes set a fixed width — `xs` 320px, `sm` 440px, `md` 512px, `lg` 48rem — capped at 100% of the container. At 768px and below every size goes full width. An `<img>` inside the figure is made a full-width block. A figure placed straight after a [`Container`](?path=/docs/components-layout-container--docs) has no top margin, so it sits flush against the section above instead of taking the gap `Main` puts between layout blocks.

## Design tokens

| Token                          | Used for                                         |
| ------------------------------ | ------------------------------------------------ |
| `--parlour--spacing-small`     | Caption padding, top and bottom                  |
| `--parlour--spacing-medium`    | Caption padding, sides; vertical figure margin   |
| `--parlour--spacing-large`     | Gap between a floated figure and the text beside |
| `--parlour--radius-md`         | Corner radius of the frame                       |
| `--parlour--color-neutral-100` | Caption background                               |
| `--parlour--color-neutral-800` | Caption text                                     |
| `--parlour--font-size-small`   | Caption text                                     |

The four size widths (`320px`, `440px`, `512px`, `48rem`) are raw values rather than design tokens.

## Accessibility

- `<figure>` with a `<figcaption>` ties the caption to the media, so screen readers can announce them together.
- The caption doesn't replace alt text. Give every `<img>` its own `alt` describing the image, and `alt=""` only if it's purely decorative.
- Floating changes only the visual position. The figure keeps its place in the reading order, so put it in the DOM next to the text it belongs with.
- The caption's `neutral-800` text on `neutral-100` passes WCAG AA.
- `Figure` doesn't spread extra props, so it can't take `aria-*` attributes or a `className`.

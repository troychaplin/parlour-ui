# GridGroup

A CSS grid container that lays its children out in equal-width columns and collapses to one column on smaller screens. Renders a `<div>` by default, or the element set by `as`. It mirrors the grid half of the WordPress Group block; [`FlexGroup`](?path=/docs/components-layout-flex-group--docs) covers the flex half.

## When to use

- Lay out a collection of equal items — cards, tiles, features — in rows of up to `columns` across.
- Use it when the column count should follow the screen size: columns appear at the same viewport breakpoints [`Column`](?path=/docs/components-layout-column--docs) uses, and phones always get one column.
- Use [`FlexGroup`](?path=/docs/components-layout-flex-group--docs) for content-sized items in a row, and [`Column`](?path=/docs/components-layout-column--docs) for fixed content splits such as two-thirds and one-third.

## Import

```tsx
import { GridGroup } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Up to three columns of cards — columns={3} is the default; there's no gap until you set one
<GridGroup gap="medium" maxWidth="alignwide">
    <Card>…</Card>
    <Card>…</Card>
    <Card>…</Card>
</GridGroup>

// Two columns above 600px, one below
<GridGroup columns={2} gap="medium">…</GridGroup>

// Rules between the columns, or a framed table of rows and columns
<GridGroup dividers="columns">
    <Card border={false}>…</Card>
    <Card border={false}>…</Card>
</GridGroup>
<GridGroup dividers="all" dividerColor="medium">…</GridGroup>

// A list of cards
<GridGroup as="ul" gap="medium">
    <Card as="li">…</Card>
    <Card as="li">…</Card>
</GridGroup>
```

### Default

Three cards in the wide width. On screens 768px wide and narrower they stack into one column.

### Column counts

`columns` is the most columns the grid shows, and it takes effect at the viewport breakpoints: two columns above the 600px mobile breakpoint, three above the 768px tablet breakpoint. Below its breakpoint a grid is one column, so a three-column grid never shows two.

<Canvas of={GridGroupStories.ColumnCounts} />

### As a list

`as="ul"` with each `Card` rendered `as="li"` gives screen readers a list and its item count. The bullets and indent are removed.

<Canvas of={GridGroupStories.AsList} />

### Dividers between columns

`dividers="columns"` draws a 1px rule between side-by-side items. When the grid stacks to one column, the rules turn horizontal and sit between the items. Leave `gap` and `rowGap` unset so the items touch the rules, and give each item its own padding: a `Card` with `border={false}` sits flush against the rules, with its padding insetting the content. Each rule is drawn inside an item's edge, so with a gap set it would hug one item with the gap on its other side.

<Canvas of={GridGroupStories.DividersBetweenColumns} />

### Dividers on every row and column

`dividers="all"` frames the grid and rules every row and column, like a table. As with `columns`, the items touch the rules and the frame. An incomplete last row leaves its empty slots unruled.

<Canvas of={GridGroupStories.DividersAll} />

### Dividers on a dark section

Dark `Card`s on a dark `Container`. `dividerColor` sets the rule colour: `white`, `light` (default), `medium` or `dark`, the same set as `Card`'s and `ProjectCard`'s `borderColor`. Choose one with enough contrast against the section behind the grid.

## CSS classes

| Class                                                     | When applied                                                                                                                                                  |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `parlour-layout`                                          | Always — shared marker on layout components                                                                                                                   |
| `parlour-grid-group`                                      | Always — base class, carries the grid with one column                                                                                                         |
| `parlour-grid-group--columns-{n}`                         | Always — the `columns` value, e.g. `parlour-grid-group--columns-3` (default). `--columns-2` shows two columns above 600px and `--columns-3` three above 768px |
| `parlour-grid-group--gap-{step}`                          | `gap` is set — e.g. `parlour-grid-group--gap-medium`. No class and no gap when it isn't                                                                       |
| `parlour-grid-group--row-gap-{step}`                      | `rowGap` is set                                                                                                                                               |
| `parlour-grid-group--align-{value}`                       | `align` is set — `start`, `center`, `end` or `stretch`                                                                                                        |
| `parlour-grid-group--dividers-{value}`                    | `dividers` is `columns` or `all`. `none` (default) adds no class                                                                                              |
| `parlour-grid-group--divider-{color}`                     | `dividers` is `columns` or `all`. The `dividerColor` value, e.g. `parlour-grid-group--divider-light` (default). Never applied with `dividers="none"`          |
| `aligncontent` / `alignwide` / `alignfull` / `alignsmall` | The `maxWidth` value, as a bare shared class                                                                                                                  |

The row-gap modifiers come after the gap modifiers in the stylesheet, so `rowGap` overrides the row half of `gap`. The divider colour modifiers set `--parlour-grid-group-divider`. The rules are each item's `::before` (column) and `::after` (row), drawn inside the item's start and top edges, so items in a divided grid are `position: relative`. A `Card` with a border would draw it beside the rule, so turn the border off. The rules follow each item's height, so leave `align` at its default of `stretch`. A `className` you pass is appended after these classes.

## Design tokens

| Token                                                       | Used for                                                                                               |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `--parlour--spacing-*`                                      | `gap` and `rowGap` — any step of the spacing scale, or `none`                                          |
| `--parlour--color-white` / `-neutral-300` / `-500` / `-900` | The `white`, `light`, `medium` and `dark` divider colours, the same as `Card`'s border colours         |
| `--parlour--layout-*-size`                                  | `maxWidth`, through the shared `align*` classes                                                        |
| `$parlour-viewport-mobile` / `$parlour-viewport-tablet`     | The 600px and 768px column breakpoints, through the generated `above-mobile` and `above-tablet` mixins |

Media queries can't read CSS custom properties, so the breakpoints use the SCSS variables generated from the `viewport` tokens rather than `--parlour--*` properties.

## Accessibility

- `GridGroup` only arranges its children and adds no semantics of its own; the default `<div>` isn't announced.
- The grid never reorders items, so keyboard and reading order match what's on screen.
- For a collection, render `as="ul"` (or `ol`) with each child as an `li` — `Card as="li"` — so screen readers announce a list and its item count.
- A grid rendered as `ul` or `ol` gets `role="list"`. Removing the bullets with `list-style: none` otherwise makes Safari and VoiceOver stop announcing it as a list. Pass your own `role` to override it.

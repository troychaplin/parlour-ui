# Hero Header

The heading block that opens a page: an optional prefix line, a large title with an optional italic accent, and whatever you pass as children. Renders a `<header>` containing an `<h1>`, or the heading level set by `level`.

## When to use

- Lead the page, usually as the first thing in its opening [`Container`](?path=/docs/components-layout-container--docs) — on its own, or in a two-column [`GridGroup`](?path=/docs/components-layout-grid-group--docs) next to a code sample or image.
- Add a stats row, an intro paragraph or actions below the title by passing them as children.
- Don't use it for the sections further down the page — [`SectionHeader`](?path=/docs/components-content-section-header--docs) is the smaller heading for those — or for the site-wide header, which is `SiteHeader`.

## Import

```tsx
import { HeroHeader } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Title only — renders an <h1>
<HeroHeader title="Plugins, projects" />

// Prefix and italic accent
<HeroHeader
    prefix="Building for the open web."
    title="Plugins, projects"
    titleAccent="& open source contributions"
/>

// Stats row passed as children
<HeroHeader title="Plugins, projects">
    <ul className="parlour-hero-header__stats">
        <li>7 released plugins</li>
        <li>5 experimental projects</li>
    </ul>
</HeroHeader>

// Mono uppercase prefix, matching SectionHeader's — prefixStyle is italic (default) or mono
<HeroHeader prefix="// Latest writing" prefixStyle="mono" title="From the" titleAccent="front of the editor." />

// Smaller, for a header inside a column — size is small, medium, large (default) or x-large
<HeroHeader size="small" level={2} title="From the" titleAccent="front of the editor." />

// Next to a code sample: side by side above 600px, stacked below
<Container color="pale" maxWidth="alignfull" contentWidth="alignwide">
    <GridGroup columns={2} gap="3-x-large" align="center">
        <HeroHeader title="Plugins, projects" titleAccent="& open source contributions" />
        <CodeBlock code={code} />
    </GridGroup>
</Container>
```

### Prefix styles

`prefixStyle` switches the prefix between the light italic line (`italic`, default) and a small mono uppercase label (`mono`), the same style as [`SectionHeader`](?path=/docs/components-content-section-header--docs)'s prefix. It works at any `size`.

### Sizes

`size` scales the title and the space below the prefix: `large` (default) opens a page, `x-large` makes a bigger statement on a sparse landing page, `medium` and `small` fit a section or a column. The accent, prefix text and colours are the same at every size.

## CSS classes

| Class                                  | When applied                                                                                    |
| -------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `parlour-hero-header`                  | Always — base class                                                                             |
| `parlour-hero-header--{size}`          | Always — the `size` value, e.g. `parlour-hero-header--large` (default)                          |
| `parlour-hero-header__prefix`          | `prefix` is set — on the `<p>` above the title                                                  |
| `parlour-hero-header__prefix--{style}` | `prefix` is set — the `prefixStyle` value, e.g. `parlour-hero-header__prefix--italic` (default) |
| `parlour-hero-header__title`           | `title` is set — on the heading                                                                 |
| `parlour-hero-header__title-accent`    | `titleAccent` is set — on the `<span>` inside the heading                                       |
| `parlour-hero-header__stats`           | Never added by the component — put it on a `<ul>` you pass as children                          |

The size modifiers set `--parlour-hero-header-title-size`, `--parlour-hero-header-tracking` and `--parlour-hero-header-prefix-gap`, which the title and prefix read. A `className` you pass is appended after these classes. The stats row styles only apply to a `ul.parlour-hero-header__stats` inside the header, so the class has no effect elsewhere.

| Token                                   | Used for                                                          |
| --------------------------------------- | ----------------------------------------------------------------- |
| `--parlour--font-size-5-x-large`        | Title font size, `x-large`                                        |

| `--parlour--font-size-2-x-large`        | Title font size, `small`                                          |

| `--parlour--color-neutral-900`          | Title color, outside dark and medium Containers                   |
| `--parlour--color-white`                | Title color inside dark and medium Containers                     |
| `--parlour--font-family-source-serif-4` | Accent font family                                                |
| `--parlour--font-weight-extra-light`    | Accent font weight                                                |
| `--parlour--font-size-medium`           | `italic` prefix font size                                         |
| `--parlour--font-family-jetbrains-mono` | `mono` prefix font family                                         |
| `--parlour--font-size-2-x-small`        | `mono` prefix font size                                           |
| `--parlour--color-neutral-600`          | `mono` prefix colour                                              |
| `--parlour--color-neutral-300`          | `mono` prefix colour in dark and medium Containers; stats divider |
| `--parlour--font-weight-light`          | `italic` prefix and stats font weight                             |
| `--parlour--spacing-4-x-large`          | Space below the prefix, `x-large`                                 |
| `--parlour--spacing-3-x-large`          | Space below the prefix, `large`                                   |
| `--parlour--spacing-2-x-large`          | Space below the prefix, `medium`; stats gap                       |
| `--parlour--font-size-small`            | Stats font size                                                   |
| `--parlour--spacing-x-large`            | Space below the prefix, `small`; above stats                      |
| `--parlour--spacing-medium`             | Space between the stats divider and the items                     |

The title's `line-height` (`1.1`) and `letter-spacing` (`-2.5px`, `-2px`, `-1.5px` and `-1px` by size), the `mono` prefix's `letter-spacing` (`0.1em`), and the stats divider's `1px` width use raw values rather than design tokens.

## Accessibility

- `HeroHeader` renders a `<header>`. `Hero` renders a `<section>`, so it's a grouping element there rather than a second `banner` landmark next to the site header. If you use it outside a `Hero`, keep it inside [`Main`](?path=/docs/components-template-parts-main--docs) for the same reason.
- The title is the page's `<h1>` by default, so use one `HeroHeader` per page. Pass `level={2}` only when something else on the page is the main heading.
- `titleAccent` is part of the heading. A space separates it from `title`, so screen readers announce the whole phrase as one heading; the italic styling is visual only.
- The prefix is a paragraph before the heading, not part of it. Screen reader users who jump between headings skip it, so don't put information only there.
- A stats list is announced as a list with its item count. Write each item as a complete phrase ("7 released plugins"), not a bare number.
- The title is `--parlour--color-neutral-900` on light backgrounds and turns white inside dark and medium `Container`s at every heading level, `<h1>` included. The `italic` prefix and the stats inherit the surrounding text color, so they follow the container too. The `mono` prefix is `--parlour--color-neutral-600`, and `--parlour--color-neutral-300` inside dark and medium `Container`s, the same as `SectionHeader`'s.

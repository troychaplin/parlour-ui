# Column

A responsive CSS grid container that arranges its children into equal or fractional column splits. Includes a `Column.Content` sub-component that enables DOM-order-independent visual reordering — content-first on mobile, sidebar-first on desktop.

## When to use

- Lay out page content in columns inside a [`Container`](?path=/docs/components-layout-container--docs) — a two-thirds/one-third article-plus-sidebar split, or equal columns of prose.
- Use `Column.Content` with `isFirst` when a sidebar should come first visually on wide screens but after the main content in the DOM.
- Don't use it for a grid of cards or other repeated items — that's [`GridGroup`](?path=/docs/components-layout-grid-group--docs). For a single full-width column, skip `Column` and place content directly in the `Container`.

## Import

```tsx
import { Column } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Equal columns
<Container>
    <Column cols="3">
        <Column.Content>...</Column.Content>
        <Column.Content>...</Column.Content>
        <Column.Content>...</Column.Content>
    </Column>
</Container>

// Two-thirds / one-third split
<Container>
    <Column cols="2/3">
        <Column.Content>Main content</Column.Content>
        <Column.Content>Sidebar</Column.Content>
    </Column>
</Container>
```

### Content first — `isFirst`

The `isFirst` prop on `Column.Content` controls visual order independently of DOM order. In the example below the sidebar is second in the DOM (better for screen readers and mobile stacking) but appears first visually on desktop via CSS `order`.

<Canvas of={ColumnStories.ContentFirst} />

```tsx
<Column cols="1/3">
    {/* First in DOM → first on mobile, second on desktop */}
    <Column.Content>
        <p>Main content</p>
    </Column.Content>

    {/* Second in DOM → second on mobile, first on desktop via isFirst */}
    <Column.Content isFirst>
        <p>Sidebar</p>
    </Column.Content>
</Column>
```

## Column configurations

| `cols`  | Up to 600px | 601px–768px | Above 768px |
| ------- | ----------- | ----------- | ----------- |
| `"1"`   | 1 column    | 1 column    | 1 column    |
| `"2"`   | 1 column    | 2 columns   | 2 columns   |
| `"3"`   | 1 column    | 1 column    | 3 columns   |
| `"4"`   | 1 column    | 2 columns   | 2 columns   |
| `"1/3"` | 1 column    | 1 column    | 33% / auto  |
| `"2/3"` | 1 column    | 1 column    | 66% / auto  |

## Sub-component — Column.Content

`Column.Content` is a lightweight wrapper `<div>` that participates in the grid's ordering system.

| Prop      | Default | Description                                                     |
| --------- | ------- | --------------------------------------------------------------- |
| `isFirst` | `false` | Moves this child to the front once the columns sit side by side |

Every other child keeps its DOM order, whether it's a `Column.Content` or another element such as an [`Aside`](?path=/docs/components-layout-aside--docs). `isFirst` only takes effect at the widths where the columns sit side by side — above 600px for `cols="2"` and `"4"`, above 768px for `"3"`, `"1/3"` and `"2/3"`, and never for `"1"` — so stacked columns on small screens always follow the DOM.

## CSS classes

| Class                        | When applied                              |
| ---------------------------- | ----------------------------------------- |
| `parlour-column`             | Always — base grid container              |
| `parlour-column--one`        | `cols="1"`                                |
| `parlour-column--two`        | `cols="2"`                                |
| `parlour-column--three`      | `cols="3"`                                |
| `parlour-column--four`       | `cols="4"`                                |
| `parlour-column--one-third`  | `cols="1/3"`                              |
| `parlour-column--two-thirds` | `cols="2/3"`                              |
| `parlour-column__content`    | Always — on `Column.Content`              |
| `is-first`                   | On `Column.Content` when `isFirst={true}` |

The root also gets `parlour-layout` and the `maxWidth` value (`aligncontent` by default, `alignwide` or `alignfull`), the shared alignment classes that set its width. Inside each `parlour-column__content`, the first child's top margin and the last child's bottom margin are removed.

## Design tokens

| Token                      | Used for            |
| -------------------------- | ------------------- |
| `--parlour--spacing-large` | Gap between columns |

The split widths (`33%`, `66%`) are raw values rather than design tokens.

## Accessibility

- `Column` renders a plain `<div>` — no landmark role. Landmark semantics belong to the content inside (`Article`, `Aside`, etc.).
- The `isFirst` pattern preserves a logical DOM order for screen readers and keyboard users while allowing visual reordering for sighted users. Use it when a sidebar should appear on the left on desktop but after the main content on mobile.
- Avoid placing interactive content (forms, navigation) in a column order that diverges significantly from the visual order, as tab order follows the DOM, not the visual layout.

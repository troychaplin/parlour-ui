# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Prefix the change with one of these keywords:

- _Added_: for new features.
- _Breaking_: for higher visibility of breaking changes
- _Changed_: for changes in existing functionality.
- _Deprecated_: for soon-to-be removed features.
- _Removed_: for now removed features.
- _Fixed_: for any bug fixes.
- _Security_: in case of vulnerabilities.

## [Unreleased]

_Changed_ `Quote` has `spacing-2-x-large` above and below it, so a pull quote in body copy no longer sits against the paragraph before it.

_Changed_ A `Figure` placed straight after a `Container` has no top margin, so it sits flush against the section above.

_Added_ `Figure` `maxWidth` prop (`alignsmall`, `aligncontent`, `alignwide`, `alignfull`) for block figures, matching `Container`. Floated figures keep using `size`.

_Added_ `PostMeta`, a post byline with the author's avatar, name and details, and the published and updated dates.

_Added_ `SectionHeader` `maxWidth` prop (`alignsmall`, `aligncontent`, `alignwide`, `alignfull`), matching `ContentList` and `Container`.

_Added_ `SectionHeader` `description` prop: an intro paragraph below the title, sized to match `size`.

_Added_ `Container` `border` prop (`none`, `top`, `bottom`, `both`, `all`) with a border colour matched to each `color`. `none` is the default.

_Breaking_ `light` and `white` Containers are no longer bordered by default. Add `border="all"` to keep the previous look (top and bottom only on full-width Containers).

_Fixed_ Two stacked full-width bordered `Container`s drew a doubled line where they meet.

_Changed_ Rewrote the `Container` docs and stories, which still described the removed `bgType` prop.

_Added_ `SectionHeader` `divider` prop (`0`–`4`) for the rule's width in pixels. `1` is the default and matches the previous rule; `0` removes the rule and the space above it.

_Fixed_ `FlexGroup`'s `gap`, `padding` and `margin` had no effect for any value but `none`: the generated classes had a doubled dash (`parlour-flex-group--gap--large`) since the rename to `parlour` in 0.3.0. `SiteHeader` and `InfoBar` now get their intended gap when their items wrap.

_Added_ `Pagination`, links between the pages of a long list, with `color` fills matching `Container`'s backgrounds and `align` (`start`, `center`, `end`).

_Added_ `SectionHeader` `level={1}` for a page's main heading, and a `size` prop (`small`, `medium`, `large`, `x-large`) for the title. `medium` is the default and matches the previous size.

_Added_ `HeroHeader` `size="x-large"`, a step above `large`.

## [0.4.0] - 2026-11-06

_Added_ `Quote` for a large italic pull quote, with an optional mono `prefix` above it and a `cite` attribution below.

_Added_ `ContentList` `backgroundHover` options `light-subtle` and `dark-subtle`, lighter overlays for when `light` or `dark` is too heavy.

_Added_ `overlay-light-subtle` (white at 10%) and `overlay-dark-subtle` (black at 5%) colour tokens, CSS only.

_Added_ A linked `ContentList` row's title changes to `accent-secondary` on hover (`accent-secondary-light` in dark and medium Containers), as a linked `ProjectCard`'s does.

_Added_ `BrandIcon` `text` prop that renders a short label beside the icon, centred vertically with it at 80% of the icon's size (60% from `2-x-large` up), a `color` prop that takes any colour token, and a `size` prop that takes the font-size tokens from `2-x-small` to `5-x-large`.

_Added_ `ContentList` and its parts (`ContentListItem`, `ContentListIndex`, `ContentListMeta`, `ContentListLabel`, `ContentListImage`, `ContentListBody`, `ContentListTitle`, `ContentListExcerpt`) for ruled post listings whose columns you choose and order per layout.

_Added_ `HeroHeader` `prefixStyle` prop: `italic` (default, the previous style) or `mono`, a small uppercase label matching `SectionHeader`'s prefix.

_Added_ `HeroHeader` `size` prop (`small`, `medium`, `large`) for smaller headers in sections and columns. `large` is the default and matches the previous styles.

_Breaking_ `GridGroup`'s `gap` no longer defaults to `medium`. A grid has no gap until you set one, matching `FlexGroup`; add `gap="medium"` to keep the old spacing.

_Added_ `Card` `backgroundHover` prop (`light`, `dark`) that tints a linked card's background with a translucent overlay on hover.

_Added_ `overlay-light` (white at 5%) and `overlay-dark` (black at 7%) colour tokens, CSS only.

_Added_ `GridGroup` `dividers` (`none`, `columns`, `all`) and `dividerColor` props for grids ruled between columns or framed like a table. Leave `gap` unset and items such as `Card` sit flush against the rules.

_Changed_ `Article` and `Aside` move from Template Parts to Layout in Storybook. The package exports don't change.

_Breaking_ `Hero` is removed. Compose a page's opening band from `Container` and `GridGroup` (or
`FlexGroup`) instead — see the `HeroHeader` docs for the heading-and-code layout.

_Breaking_ `Card` no longer takes `href` or `linkProps`. Put a `CardLink` inside the card instead, usually around its heading text — it stretches over the whole card.

_Added_ `CardLink`, a link that makes its whole `Card` clickable while its accessible name stays its own text.

_Fixed_ Linked `Card` and `ProjectCard` failing axe 4.14's `label-content-name-mismatch` rule (WCAG 2.5.3 Label in Name).

## [0.3.0] - 2026-10-07

_Added_ `--parlour--color-accent-primary-light` and `--parlour--color-accent-secondary-light`, light
versions of the accents that stay readable on `neutral-900` and darker. Both are in the WordPress
palette too.

_Added_ `ProjectCard` colours for `medium` and `dark` backgrounds: light neutrals for the text,
icon and divider, and the light accents for the hover colours. Each part's colour is a
`--parlour-project-card-*` custom property you can override.

_Fixed_ The focus outline on a linked `Card` with a `medium` or `dark` background uses
`accent-primary-light`, since `accent-primary` was too dark to see there.

## [0.2.3] - 2026-10-07

_Changed_ `Hero` renders its row straight away as a `<div>` at the wide content width, without the
full-width `<section>` `Container` it used to wrap it in. Place it inside a `Container` to give it a
full-width band, side padding or a background colour.

## [0.2.2] - 2026-10-06

_Changed_ `SiteHeader` takes its navigation links from a `navItems` prop, and its buttons from
`children`, which now fill the actions area at the end of the row. They replace the built-in About,
Blog and Resume links and Sponsor Me button. Without them, the header shows only the title.

_Fixed_ A `Button` with an `href` now gets its colour's border. The link version had a transparent
border that outranked the colour modifiers, so outline buttons rendered as links had no outline.

## [0.2.1] - 2026-10-06

_Added_ A `wordpress` prop on `SiteFooter` for a WordPress.org profile link, shown after GitHub.

## [0.2.0] - 2026-10-06

_Added_ `SiteFooter`, the page footer: a copyright line with a name, an optional line of text in
the middle, and round social links for GitHub, X, Bluesky, LinkedIn, Facebook, Instagram,
YouTube and TikTok, each shown only when its profile URL is set.

_Added_ `BrandIcon` icons for X, Bluesky, LinkedIn, Facebook, Instagram, YouTube and TikTok, and a
`--parlour--color-github` token.

_Added_ `SkipLink`, a link that stays hidden until it gets keyboard focus and then jumps past the
header to the page's main content. It targets `#main` by default.

_Changed_ `Main` renders with `id="main"` and `tabIndex={-1}` by default, so a skip link can move
focus into it. Pass `id` or `tabIndex` to override either.

_Added_ `BrandIcon`, single-colour logos for React, WordPress, Next.js, Storybook, npm and other
tools, from Simple Icons. Each takes the size and colour of the text around it.

_Added_ `ProjectCard`, a card for a software project built on `Card`: a type eyebrow and brand icon, a title, a version, a description and a footer line, with the whole card linking to
`href`. Sample projects for stories live in `src/data/ProjectData.json`.

_Added_ `href` and `linkProps` on `Card`. With `href`, the card wraps its children in a link from
`LinkProvider` that fills the card and takes over its padding, so the whole card is clickable and
`paddingInline` and `paddingBlock` still set the spacing. `linkProps` passes attributes such as
`aria-labelledby` to the link.

_Changed_ `Card` is now a client component (`'use client'`), since it reads `LinkProvider`.

_Changed_ `Card` moves to a new Cards section in Storybook, alongside the design cards built on it.

_Breaking_ `Card` replaces its `padding` prop with `paddingInline` and `paddingBlock`, so the sides
and the top and bottom can be set separately. Both default to `large`, which matches the old
default. The `parlour-card--padding-{step}` classes are now `parlour-card--padding-inline-{step}`
and `parlour-card--padding-block-{step}`.

## [0.1.0] - 2026-10-04

The first release under the Parlour name. The project was formerly developed as "Octave Design
System" and published as `@troychaplin/octave-design-system`. It now ships as
`@troychaplin/parlour-ui`, and the version history starts again here. Code written against the old
package needs the new package name in its imports, `--parlour--` in place of the `--octave--`
custom properties, and `parlour-` in place of the `octave-` class names.

_Added_ A token pipeline. Colors, three font families with bundled font files, 16 fluid type
sizes, a 12-step spacing scale, shadows, radii and layout widths are defined once in
`c2b.config.json`, and `@troychaplin/component2block` generates them as `--parlour--*` custom
properties, SCSS variables and breakpoint mixins, base element styles, layout classes and the
`parlourTokens` JavaScript export.

_Added_ WordPress outputs in `dist/wordpress/`: `theme-parlour.json` with the tokens as
`theme.json` presets, `integrate.php` to load it as WordPress's default `theme.json` layer, and
`block-theme.css` and `hybrid-theme.css` for block and hybrid themes. Each component's CSS is also
published on its own, so a block can bundle only what it renders.

_Added_ Accessibility checks. Every Storybook story runs through axe at the `error` threshold, in
CI and on pre-push, so a violation fails the build.

_Added_ Components: Elements (`Button`, `ButtonGroup`), Content (`Card`, `CodeBlock`, `Figure`,
`Hero`, `HeroHeader`, `SectionHeader`), Layout (`Column`, `Container`, `FlexGroup`, `GridGroup`),
Template Parts (`Article`, `Aside`, `Body`, `InfoBar`, `Main`, `SiteHeader`) and Utilities
(`LinkProvider`). They ship as ES modules and CommonJS with TypeScript types, and work in Next.js
Server Components.
